# Contributing to Linux System Info

Thank you for your interest in contributing to Linux System Info! 🐧

This project is a simple Bash-based tool that displays useful information
about a Linux system.

Contributions, suggestions, bug reports, and improvements are welcome.

## Getting Started

1. Fork this repository.
2. Clone your fork.

```bash
git clone https://github.com/YOUR-USERNAME/linux-system-info.git
