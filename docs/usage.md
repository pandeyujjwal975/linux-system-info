# Linux System Info — Usage Guide

A practical guide for installing, running, testing, and understanding `Linux System Info`.

---

## 1. Requirements

Before using the project, make sure you have:

- Linux operating system
- Bash 4.x or newer
- Standard Linux command-line utilities
- Git (only required for cloning the repository)

No database, API key, or external framework is required.

---
